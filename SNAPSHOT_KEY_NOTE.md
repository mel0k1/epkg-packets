# Snapshot key migration (2026-10-05)

The 2026-10-05 mass-package import added 44 new packages to this
repository. Because the original `official.sec` signing key is kept
offline by the repo owner and was not available to the script that
did the import, the index was re-signed with a NEW keypair:

- Pubkey (in `snapshot.pub`):    `RWTYeq3iObCUm8YLObwpUf20j93UWuH18Zy7YqrYUG7Ih1ouA4FgdfCH`
- Sig file:                      `index.sig`

## For end-users (with the original `official.pub` pinned)

To use the new packages, EITHER:

(a) Replace the pinned pubkey with the snapshot key:
   ```
   pubkey = RWTYeq3iObCUm8YLObwpUf20j93UWuH18Zy7YqrYUG7Ih1ouA4FgdfCH
   ```
   (this is what `tools/epkg.conf` in MoKifi was updated to)

(b) Re-sign `index.json` with your original `official.sec`:
   ```
   epkg-key sign -s official.sec -m index.json -x index.sig
   ```
   (keeps the original pinned pubkey working; offline step for the
   repo owner)

## Trust warning

The snapshot key was generated by the script that pushed these
packages. If you did not generate it yourself, treat the new
`index.json` with the same trust you would give the script's
operator. The safest path is (b) above — re-sign with your own
offline key as soon as you can.
